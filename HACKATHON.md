# Hackathon scope

All code in this repository was written during the 2026 AI Builders Hackathon
submission period (Aug 21 – Sep 15, 2026).

Reused third-party libraries and boilerplate, all listed in `apps/api/pyproject.toml`
and `apps/web/package.json`:

- FastAPI, SQLAlchemy, structlog, sse-starlette, pytest, coverage.py
- Next.js (create-next-app scaffold), Tailwind, shadcn/ui
- Stripe Pricing Table embed (no-code, test mode)

The mutation engine, diff scoper, isolated runner, gate, and evaluation harness
are original to this project.
