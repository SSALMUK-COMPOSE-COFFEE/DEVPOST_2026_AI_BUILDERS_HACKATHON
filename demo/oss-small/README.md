# demo/oss-small

Vendored copy of **inflection 0.5.1** (MIT), a real single-module
open-source package for singularizing and pluralizing English words.

- Upstream: https://github.com/jpvanhal/inflection
- License: MIT (see `LICENSE`, unmodified)
- Files: `inflection/__init__.py` and the upstream `test_inflection.py` are
  copied verbatim from the PyPI sdist.

It is here to show KillScore running on code nobody on this team wrote.
